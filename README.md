# Source-Pymeomeo
PyMeoMeo – Python Obfuscation Tool 

PyMeoMeo là một trong những công cụ obfuscate mã nguồn Python mạnh mẽ.
Được xây dựng và duy trì bởi Vương Tiến Đạt GitHub: https://github.com/hngocuyen, PyMeoMeo đã nhanh chóng trở thành một trong những lựa chọn hàng đầu của cộng đồng khi cần bảo vệ script thương mại, tool bảo mật và các dự án Python nhạy cảm.

Sau một thời gian dài được phát hành dưới dạng private tool, tác giả đã quyết định public source code hoàn chỉnh để cộng đồng có thể nghiên cứu, học hỏi và phát triển thêm.

🚀 Tính năng nổi bật

Control‑flow obfuscation nâng cao
Chia nhỏ và làm rối luồng điều khiển, thêm nhiều nhánh giả, đảo logic giúp việc phân tích ngược khó hơn rất nhiều.

String encryption nhiều lớp
Mã hóa chuỗi bằng nhiều thuật toán khác nhau, chỉ giải mã khi runtime, gây khó khăn cho decompiler.

Bytecode customization
Một số bản có tích hợp chỉnh sửa bytecode thủ công, khiến các tool giải mã thông thường gặp lỗi hoặc output sai.

Anti‑reverse engineering
Thêm các cấu trúc gây nhiễu, trick AST parser, gây crash khi người ta cố đọc mã nguồn.

Obfuscation đa tầng
Kết hợp encode, compress, lambda splitting, dynamic execution — tạo output rối cực mạnh.
